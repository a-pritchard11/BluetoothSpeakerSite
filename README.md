<h1>Pritchard_Alexander_Bluetooth_Speaker_Website</h1>
<p>This repository is for a showcase of a bluetooth speaker model through use of the model viewer plugin and other javascript effects. <br>
It includes the modelviewer with interactive features like hotspots, as well as a fluid rotation. In addition, it also features a javascript and greensock powered image sequence scroll sensitive animation, as well as a comparison slider to view a separate image of the model.
</p>

<h2>Installation</h2>
<p>No installation required. Simply download the zip file and extract.</p>

<h2>Usage</h2>
<p>Open index.html in the browser of your choice.</p>
